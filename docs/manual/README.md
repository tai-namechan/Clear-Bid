# Clear Bid セットアップマニュアル

ジュニア向けの手順書です。

## 開き方

1. ファイルを開く: [`clear-bid-setup-manual.html`](./clear-bid-setup-manual.html)
2. ブラウザ（Chrome / Edge / Safari など）で開く  
   - Finder / エクスプローラーでファイルをダブルクリックでも可  
   - または Cursor 上で右クリック → Reveal in Finder など
3. PDF にしたいとき: 画面上部の **「PDFとして保存 / 印刷」** → プリンタを **「PDFに保存」**

技術者向けの短い手順は [`../DEPLOY.md`](../DEPLOY.md) を参照。
